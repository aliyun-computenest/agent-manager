# v1.0.6

- **发布日期**：2026-07-17

## 新增功能

### AI 应用可观测性（APM）

- 新增 AI 应用监控能力，支持 OpenClaw、Hermes 和 QwenPaw 接入阿里云 ARMS APM。
- Agent 实例创建完成后，发起一次对话即可开始上报监控数据，无需手动安装探针。
- 管理员可以在 `运行监控 -> 应用监控` 中查看实例的调用链路、对话分析、Token 消耗和模型调用耗时等指标。
- Agent 类型配置页新增采集开关，管理员可以一键开启或关闭监控采集，切换后无需重建实例即可生效。
- 服务首次部署时会自动从 CMS API 获取 ARMS 接入参数并写入配置，管理员无需手动填写。

### 应用监控诊断

- 应用监控页面新增实例级状态诊断，自动检查参数配置、采集开关、探针安装和实体注册状态。
- 采集关闭时，页面会显示原因和处理提示，并支持跳转到 Agent 类型配置页开启采集。

## 升级步骤

请参考[升级计算巢服务实例](./README.md#升级计算巢服务实例)，在阿里云计算巢控制台对服务实例执行升级。数据库迁移会随升级流程自动完成。

## 注意事项

- **确认 xtrace 写入通道**：升级后，请在阿里云云监控 2.0 控制台确认对应工作空间的 trace 写入通道已开启，否则监控数据无法上报。
- **老实例接入监控**：已运行的老实例需要通过 `实例升级` 更新镜像后才能接入应用监控；新建实例无需额外安装探针。
- **开启采集开关**：升级后，内置 Agent 类型的采集开关默认为关闭。管理员需要手动开启，后续新建实例才会上报监控数据。
- **QwenPaw 限制**：QwenPaw 链路追踪中的输入/输出内容依赖 LoongSuite 插件版本。当前 0.7.0 版本存在 ContextVar 兼容性问题，相关展示需等待 LoongSuite 后续修复。
