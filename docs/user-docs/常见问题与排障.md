## 服务实例部署失败怎么办

先打开计算巢服务实例详情页，在基本信息区域查看状态描述。

按状态描述匹配以下原因：

| 原因 | 处理方式 |
| --- | --- |
| RAM 子账号权限不足 | 到 RAM 控制台补齐权限后，回到服务实例继续部署。 |
| 云产品配额不足 | 到配额中心申请提升配额，或降低规格后继续部署。 |
| 云资源无库存 | 更换可用区或资源规格。 |
| 余额不足或账号欠费 | 到费用与成本控制台充值或处理欠费。 |
| 云产品服务未开通 | 到对应云产品控制台开通服务。 |
| VPC 或交换机选择错误 | 选择与 Sandbox 集群匹配的 VPC 和普通交换机，不要选择 OpenClaw 专属交换机。 |

如果状态描述显示错误码，请进入阿里云错误中心查看含义。进一步排查时，打开部署日志，找到失败资源和请求 ID。

## 服务实例长时间部署中怎么办

1. 先确认该服务实例的预计部署时间。
2. 如果当前耗时仍在合理范围内，请继续等待。
3. 如果明显超时，打开服务实例部署日志。
4. 查看是否卡在 Supabase、SLB、K8s Job 或 AI 网关资源。
5. 根据日志中的错误码、请求 ID 和资源名称继续排查。

如果部署日志没有明确错误，请提交工单或联系计算巢技术支持。

## 部署成功后平台无法访问怎么办

1. 在服务实例输出中复制 `API 健康检查` 地址。
2. 打开健康检查地址。
3. 如果健康检查失败，检查平台 Deployment、Pod 日志和 Supabase 连接。
4. 如果健康检查成功但页面打不开，检查平台公网 SLB、浏览器网络和安全组。
5. 等待 1 到 2 分钟后重试，部分 SLB 或路由可能需要短暂就绪时间。

登录页能打开但登录失败时，继续查看登录相关问题。

## 用户登录页没有登录方式怎么办

用户登录页始终支持邮箱密码登录。管理员需要先在用户管理中创建用户，用户才能用邮箱和密码登录。

如果需要 OAuth 或 SAML SSO：

1. 确认 Supabase Auth 中已启用对应 Provider。
2. 确认 Agent Manager `用户管理 -> 单点登录` 页面已刷新状态。
3. 确认 OAuth 和 SAML SSO 没有同时启用。
4. 重新打开平台登录页。

## 忘记管理员密码怎么办

无法通过管理员页面登录时，使用 Supabase `service_role key` 调用 Auth Admin API 修改管理员密码。

1. 获取 Supabase URL 和 `service_role key`。
2. 调用 `/auth/v1/admin/users` 找到管理员用户 ID。
3. 调用 `/auth/v1/admin/users/<USER_ID>` 更新 `password` 字段。
4. 使用新密码登录。

`service_role key` 权限很高，请只在可信终端使用。

## 创建 Agent 实例失败怎么办

按以下顺序检查：

1. 当前用户是否达到实例数量上限。
2. 是否至少启用了一个 Agent 类型。
3. 是否至少启用了一个模型。
4. Agent 类型关联的 SandboxSet 是否存在。
5. 配置写入路径和沙箱用户是否匹配镜像。
6. 模型提供商占位符是否与 Agent 配置模板一致。
7. E2B Sandbox 服务是否可用。
8. 后端 API 日志是否有具体错误。

如果错误发生在创建沙箱阶段，优先检查 SandboxSet、E2B API Key、E2B 域名和集群资源。

## 如何访问运行中的实例

实例启动后，在实例详情页单击“进入工作台”，打开 Agent 原生界面。

当前 Agent 支持终端时，实例详情页会显示“打开终端”。支持文件上传的 Agent 可在原生界面中上传文件。

管理员可以在详情页查看 E2B Host；浏览器无需解析或直连该地址。

## 应用监控没有数据怎么办

按以下顺序检查：

1. 打开管理后台，进入 `运行监控 -> 应用监控`，并在左侧选择状态为“运行中”的实例。
2. 如果页面提示监控资源未就绪，等待资源创建完成后刷新页面。
3. 如果提示插件已安装但没有数据，打开实例应用并发起一次对话，等待监控数据产生。
4. 在 `Agent 配置` 中确认目标 Agent 类型已配置应用监控参数；未配置时，新实例不会启用应用监控。
5. 如果只有网关监控没有数据，确认当前实例使用的模型提供商满足阿里云 AI 网关监控要求。
6. 仍然没有数据时，单击“新窗口打开”重新加载监控页面，并查看页面提示的资源状态。

应用监控只展示已选实例的应用可观测信息，不会替代实例列表中的运行状态、实例升级或实例备份操作。

## 如何发起实例备份

单个实例备份从实例详情页发起。实例必须已经创建并关联可用 Sandbox，备份过程中不能同时发起其他备份或恢复。

1. 打开实例详情页。
2. 在“备份与恢复”区域单击“发起备份”。
3. 在确认页面单击“确认发起”。
4. 展开“可用备份点”查看结果。

管理员还可以在“实例备份”中创建全部实例或指定实例的立即备份、周期备份。详细操作见 [Agent 备份](Agent备份.md)。

## 从备份创建新实例失败怎么办

从备份创建会保留源实例，并创建一个新实例和新的 Sandbox。源实例没有被覆盖时，先检查以下项目：

1. 目标 Agent 类型关联的 SandboxSet 仍然存在。
2. SandboxSet 同时包含 `agent-runtime` 和 `csi` runtime。
3. `/backup` 挂载可用，备份点状态为成功。
4. 集群资源、E2B 服务和镜像仓库可用。
5. 查看新实例详情中的恢复错误和后端日志。

恢复失败时不要删除源实例。修复 SandboxSet 或集群资源后，使用同一备份点重新创建实例。

## Agent 工作台打不开怎么办

按以下顺序检查：

1. 确认实例状态为“运行中”。
2. 刷新实例详情页后重新单击“进入工作台”。
3. 确认 `NATIVE_AGENT_UI_ENABLED=true`。
4. 检查 Agent Manager Pod 到实例 E2B Host 的 DNS 和网络是否可达。
5. 检查 Agent Web 端口是否与 Agent 类型配置一致。
6. 查看 Agent Manager 后端日志中的 `native-agent-ui` 错误。

如果返回 `401` 或 `403`，重新登录并确认当前用户仍有实例访问权限。如果返回 `502`，优先检查 Sandbox、E2B 域名解析和 Agent Web 进程。

## Token 用量不显示怎么办

Token 用量统计依赖 AI 网关和日志服务。

请检查：

1. 是否启用了 AI 网关。
2. 用户创建实例时是否使用 AI 网关类模型提供商。
3. 阿里云 AccessKey 是否有 SLS 读取权限。
4. 日志服务是否正常写入。
5. 管理后台是否开启 Token 统计与限流。

未启用 AI 网关时，仪表盘和用户管理中不会显示 Token 指标。

## OAuth 登录按钮没有出现怎么办

1. 登录 Supabase 控制台。
2. 打开 `Authentication -> Providers`。
3. 确认目标 Provider 已启用。
4. 确认 Client ID 和 Client Secret 正确。
5. 回到 Agent Manager `单点登录 -> OAuth` 标签页。
6. 单击刷新。
7. 重新打开用户登录页。

如果仍然不显示，确认 OAuth 和 SAML SSO 没有同时启用。

## OAuth 回调地址怎么填

所有 OAuth Provider 统一使用 Supabase Auth callback URL：

```text
https://<Supabase URL>/auth/v1/callback
```

如果服务实例输出中包含 `OAuth App 回调地址`，请优先使用该输出值。

## SAML SSO 登录后跳到了 Supabase 页面怎么办

这通常是 Site URL 配置错误。

1. 打开管理后台。
2. 进入 `用户管理 -> 单点登录 -> SAML`。
3. 在回调地址配置中把 Site URL 设置为 Agent Manager 平台公网访问地址。
4. 保存后重新登录。

示例：

```text
http://<PlatformSlb IP>:8080
```

## 可以同时配置 OAuth 和 SAML SSO 吗

不要同时启用。平台按 OAuth 和 SAML SSO 互斥配置处理。邮箱密码登录始终可用，可与 OAuth 或 SAML SSO 并存。

可同时启用多个 OAuth Provider。OAuth 模式和 SAML SSO 模式只能选择一种。

## 新增模型提供商后模型调用失败怎么办

大概率是占位符不匹配。

检查：

1. 提供商的 `apiKeyPlaceholder` 是否与模板中的占位符完全一致。
2. 提供商的 `domainPlaceholder` 是否与模板中的占位符完全一致。
3. Agent 配置模板是否切换到对应提供商的配置段。
4. 实例是否保存配置或重启。
5. API Key 是否可用。

例如启用阿里云 AI 网关类模型时，模板需要使用 `${AI_GATEWAY_DOMAIN}` 和 `${CONSUMER_API_KEY}`。

## 修改 SandboxSet 后新配置没生效怎么办

已运行实例使用的是修改前的沙箱环境。保存 SandboxSet YAML 后，需要停止并重新启动相关实例，或通过 [Agent 升级](Agent升级.md) 迁移到新的 SandboxSet 模板。

处理步骤：

1. 打开实例列表。
2. 停止目标实例。
3. 等待状态变为已停止。
4. 再启动实例。
5. 打开实例详情页验证。

修改镜像、挂载或运行时配置时，先阅读 [Agent 升级](Agent升级.md)，用少量测试 Sandbox 验证升级流程。

## Agent 实例显示不可安全升级怎么办

不可安全升级通常表示该实例不具备备份恢复能力。

常见原因包括 SandboxSet 缺少 `agent-runtime` 或 `csi` runtime、实例创建时没有写入备份挂载信息，或 Agent 类型没有配置升级前命令和升级后恢复命令。

处理步骤：

1. 打开 `沙箱配置`，确认关联 SandboxSet 具备备份挂载能力。
2. 打开 `Agent 配置`，在目标 Agent 类型的 `备份&升级配置` 中填写升级前命令和升级后恢复命令。
3. 确认待升级实例是修复后新建或已手动补齐备份挂载能力的实例。
4. 回到 `实例升级` 页面刷新 Sandbox 列表。

旧实例如果创建时没有备份挂载信息，后续只修改 SandboxSet 不会自动补齐。重建实例，或由管理员手动补齐挂载能力后再升级。

## Agent 升级失败怎么办

先在 `实例升级` 页查看失败任务的 Reason 和 Message，判断失败发生在哪个阶段。

| 失败阶段 | 处理方式 |
| --- | --- |
| 升级前命令失败 | 检查待备份目录是否存在、`/backup` 是否可写、备份命令是否退出非 0。修复后重新发起完整升级。 |
| 镜像或 Pod 启动失败 | 检查目标镜像是否可拉取、SandboxSet 启动命令和探针是否正确。修复后删除失败任务并重试。 |
| 升级后恢复命令失败 | 检查备份包路径、恢复目录和校验文件。修复恢复命令后，可选择只执行恢复命令的升级。 |
| namespace 已有未完成任务 | 等待任务完成，或删除、修复 Failed 任务后再发起新升级。 |

详细步骤见 [Agent 升级](Agent升级.md)。

## 周期备份执行失败怎么办

先打开管理后台的“实例备份”，进入对应执行详情，确认失败实例、最近一次结果和错误信息。

| 现象 | 处理方式 |
| --- | --- |
| 没有可选实例 | 只展示运行中的实例。先启动目标实例，再创建备份执行。 |
| 指定实例备份失败 | 检查实例状态、SandboxSet 的备份挂载、OSS 权限和集群资源。 |
| 周期任务没有再次执行 | 检查任务状态和 Cron 表达式，确认任务没有被取消。 |
| 备份执行数量过多 | 调低保留数量，或取消不再需要的周期任务。取消任务不会删除已经生成的备份点。 |

必要时打开执行详情中的阿里云运维编排服务（OOS）记录，查看具体失败步骤。

## 想把沙箱部署到非 default namespace 怎么办

1. 创建目标 namespace。
2. 修改 SandboxSet YAML 中的 `metadata.namespace`。
3. 替换安全组、交换机和镜像参数。
4. 确认 Agent Manager 后端 ServiceAccount 有目标 namespace 的 RBAC 权限。
5. 创建或更新 SandboxSet。
6. 在 Agent 配置中关联该 SandboxSet。
7. 创建测试实例验证。

## E2B 域名或证书变更后平台不可用怎么办

E2B 侧更新域名或证书后，Agent Manager 侧也要同步配置。

通常需要更新：

| 配置项 | K8s 资源 | 何时更新 |
| --- | --- | --- |
| CA 证书 | Secret `e2b-ca-cert` | E2B 重新签发 TLS 证书。 |
| E2B 域名 | ConfigMap 中的 `E2B_DOMAIN` | E2B 域名变更。 |
| API Key | Secret 中的 `E2B_API_KEY` | E2B API Key 变更。 |
| Pod | Agent Manager Deployment | 任一配置变更后重启。 |

操作步骤见 [E2B 证书与域名变更指南](E2B证书与域名变更指南.md)。

## 数据库恢复后如何切换 Agent Manager

如果旧 ADB Supabase 实例故障，新实例已恢复数据，需要把 Agent Manager 的 Supabase 环境变量切到新实例。

切换前确认：

- 新实例状态为运行中。
- 新实例已完成数据恢复。
- Manager 到新实例网络互通。
- 已拿到新实例 API URL、Anon Key、Service Role Key 和 Database URL。

切换步骤见 [数据库备份恢复操作指南](更换Supabase数据库操作指南.md)。
