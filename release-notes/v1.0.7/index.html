v1.0.7¶

  • 预计发布日期：2026-08-06

新增功能¶

原生 Agent 工作台¶

  • OpenClaw、Hermes 和 QwenPaw 支持从实例详情页直接进入各自的原生界面。
  • Agent Manager 统一校验登录状态和实例权限，并在服务端代理 Agent 的页面、API 和 WebSocket 请求。
  • 浏览器无需解析或直连 E2B Sandbox 私网域名，也不再经过旧版 Nginx Agent 访问网关。
  • 支持在不同标签页同时打开多个 Agent 工作台，各标签页保持独立实例上下文。

问题修复¶

  • 修复飞书扫码自动配置在用户尚未完成授权时中断的问题。系统现在会正确处理 authorization_pending 和 slow_down 响应，并继续等待用户完成授权。

升级步骤¶

请参考升级计算巢服务实例，在阿里云计算巢控制台对服务实例执行升级。本版本不包含数据库结构变更。

注意事项¶

  • 新部署不再创建旧版 OpenResty/Nginx Agent 访问网关和对应 SLB。
  • 从旧版本升级时，ROS 模板不会主动删除已有的 Kubernetes 网关 Deployment、Service 和 Secret。确认“进入工作台”可用后，可手动清理这些遗留资源。
  • 升级后，用户统一从实例详情页的“进入工作台”访问 Agent，不再使用旧版网关访问链接。
