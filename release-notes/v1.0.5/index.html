v1.0.5¶

  • 发布日期：2026-07-10

新增功能¶

Skill 市场与在线安装¶

  • 新增 Skill 市场，支持浏览、搜索和查看 Skill 详情，包括 README、安装指引和代码语法高亮。
  • 支持从 Skill 市场在线安装 Skill 到运行中的 Agent 实例，安装完成后无需重启即可生效。
  • 创建 Agent 实例时，可以从已安装的 Skill 中选择需要挂载的 Skill。
  • Skill 市场的卡片、详情页和 SkillDisplayName 字段与计算巢页面保持一致。

OOS Checkpoint 备份恢复¶

  • 新增基于阿里云运维编排服务（OOS）的 Checkpoint 自动备份和恢复能力。
  • 支持动态发现 Sandbox，并自动执行备份任务。
  • 收敛 OOS 备份执行权限，只保留完成备份所需的操作权限。

LiteLLM 增强¶

  • LiteLLM 域名可以根据部署环境自动选择。
  • 网关监控页面新增跳转 LiteLLM 详情页的入口。

其他改进¶

  • Skill 卡片头像的字母和颜色改为根据 Skill 展示名称生成。
  • 改进 Harness 隔离环境的生命周期流水线。

升级步骤¶

请参考升级计算巢服务实例，在阿里云计算巢控制台对服务实例执行升级。数据库迁移会随升级流程自动完成。

注意事项¶

  • Skill 在线安装要求 Agent 实例处于运行中；实例已停止时，请先启动实例再安装。
  • OOS 备份恢复功能要求目标集群已部署 OOS 相关组件。
